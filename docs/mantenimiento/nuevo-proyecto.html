Preparar un proyecto nuevo para la web

Funciona sin internet y sin instalar programas (incluyendo fotos .HEIC de iPhone). Reduce las imágenes a 2400 px, estampa el logo vertical abajo al centro (blanco o negro según contraste), borra todos los datos GPS ocultos y arma el archivo de datos listo para publicar.
